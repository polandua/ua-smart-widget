UA Smart Widget — Інструкція запуску на Android (PWA)
====================================================
created - Andrii Poliakov

1. Розпакуйте архів ua_smart_widget_pwa.zip.
2. Завантажте вміст папки (index.html, manifest.json, icon.svg, sw.js) на будь-який безкоштовний HTTPS-хостинг, наприклад:
   - GitHub Pages (безкоштовно)
   - Netlify Drop (app.netlify.com/drop — просто перетягніть папку)
   - Cloudflare Pages
3. Відкрийте отримане HTTPS-посилання у Google Chrome на смартфоні Android.
4. Натисніть меню браузера (три крапки угорі праворуч) -> «Додати на головний екран» / «Встановити додаток».
5. Віджет з'явиться на робочому столі Android як окремий легкий застосунок із підтримкою офлайн-кешу.
